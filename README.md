# Aura AI

ИИ-ассистент для iPhone и Android с общим сервером.

```
AuraAI/
├── server/    сервер Aura на Node.js: ключи ИИ, аккаунты, история, файлы, подписки
├── android/   приложение для Android (Kotlin + Jetpack Compose), открывается в Android Studio
├── ios/       приложение для iPhone (Swift + SwiftUI), открывается в Xcode
├── docs/      дизайн-система (одинаковая для обеих платформ)
└── apk/       уже собранные APK для установки на Android
```

## Как это устроено

```
iPhone (SwiftUI) ─┐
                  ├──► сервер Aura ──► Claude (чат, код, идеи)
Android (Compose) ┘        │       └─► сервис изображений (генерация картинок)
                           └── база SQLite: аккаунты, чаты, файлы, подписки
```

- **Ключи API хранятся только на сервере.** В приложениях их нет, поэтому ключ нельзя вытащить из APK или IPA.
- **История синхронизируется** через сервер: войдите в один аккаунт на iPhone и Android, и чаты будут одинаковые. Свежая копия также кэшируется на устройстве, чтобы открываться без интернета.
- **Ответы идут потоком** (SSE): текст появляется по мере генерации, генерацию можно остановить.
- **Лимиты и Aura Pro** считает сервер: бесплатно 30 сообщений и 5 картинок в день, с Pro 1000 и 100 (настраивается в `.env`).

## 1. Запуск сервера

Нужен Node.js 22.13 или новее.

```powershell
cd server
npm install
copy .env.example .env
```

Откройте `server\.env` и заполните:

- `ANTHROPIC_API_KEY`: ключ Claude из https://platform.claude.com/settings/keys. Без него чат отвечает понятной ошибкой «ИИ не настроен».
- `IMAGE_API_KEY`: ключ сервиса картинок. По умолчанию используется OpenAI Images (`gpt-image-1`), подойдёт любой сервис с OpenAI-совместимым `POST /images/generations` (поменяйте `IMAGE_API_BASE` и `IMAGE_MODEL`).

Запуск:

```powershell
npm start
```

Сервер напишет адреса, например `http://192.168.1.20:8787`. Этот адрес нужен телефону: телефон должен быть в той же Wi-Fi-сети, что и компьютер.

Проверка без ключей и без расходов (регистрация, чаты, файлы, лимиты, подписки, потоковые ответы через локальную заглушку Claude):

```powershell
npm test
```

### Публикация сервера в интернете

Чтобы приложение работало не только дома, разместите папку `server` на любом хостинге с Node.js и постоянным диском (VPS, Railway, Render с диском, Fly.io с volume). Задайте переменные из `.env.example`, папку `data/` храните на постоянном диске и включите HTTPS. Потом укажите в приложениях адрес `https://…`.

## 2. Android

1. Откройте папку `android` в Android Studio и дождитесь синхронизации Gradle.
2. В `android/gradle.properties` задайте адрес сервера для первого запуска:
   - эмулятор: `aura.serverUrl=http://10.0.2.2:8787` (уже стоит);
   - телефон: `aura.serverUrl=http://IP-вашего-компьютера:8787`.

   Адрес можно поменять и в самом приложении: экран входа → «Сервер», или «Настройки» → «Сервер».
3. Запустите кнопкой ▶ или соберите APK:

```powershell
cd android
.\gradlew.bat assembleDebug
```

Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`. Его можно скопировать на телефон и установить (разрешите установку из неизвестных источников).

Уже собранные файлы лежат в папке `apk/`: `Aura-AI-debug.apk` (20 МБ) и `Aura-AI-release.apk` (2 МБ, сжат R8 и подписан отладочным ключом, поэтому подходит только для тестов). После установки на экране входа нажмите «Сервер» и укажите адрес вашего компьютера.

**Release-APK для публикации:** создайте ключ подписи (Android Studio → Build → Generate Signed App Bundle/APK), затем файл `android/keystore.properties`:

```
storeFile=aura-release.jks
storePassword=…
keyAlias=aura
keyPassword=…
```

и выполните `.\gradlew.bat assembleRelease` (или `bundleRelease` для Google Play).

## 3. iOS

Нужен Mac с Xcode 16 или новее, iOS 17+.

1. Откройте `ios/AuraAI.xcodeproj`.
2. Target **AuraAI** → **Signing & Capabilities** → выберите свою команду (Team). При необходимости поменяйте Bundle Identifier (`com.aura.ai`) на свой.
3. Адрес сервера по умолчанию задан в `ios/AuraAI/Core/SessionStore.swift` (`AppConfig.defaultServerURL`). Симулятор на том же Mac видит `http://localhost:8787`. На iPhone укажите адрес в приложении: экран входа → «Сервер».
4. Нажмите ▶.

В Debug-сборке разрешён обычный HTTP для тестового сервера (`Info-Debug.plist`). Release-сборка ходит по HTTP только внутри локальной сети, для интернета нужен HTTPS.

## 4. Подписка Aura Pro

Идентификаторы подписок одинаковые на обеих платформах: `aura_pro_monthly` и `aura_pro_yearly`.

**Тестирование без магазинов:**
- iOS: в схеме уже подключён файл `ios/AuraAI.storekit`, и покупки работают в симуляторе. Если Xcode не видит файл, выберите его вручную: Product → Scheme → Edit Scheme → Run → Options → StoreKit Configuration.
- На сервере на время тестов поставьте `PRO_TEST_MODE=true`: тестовые покупки Xcode не подписаны Apple, а этот режим их принимает. **В рабочей версии верните `false`.**

**Рабочий режим:**
- **App Store Connect:** создайте группу подписок и два продукта с этими ID. На сервер скачайте `AppleRootCA-G3.cer` с https://www.apple.com/certificateauthority/ в папку `server/certs/`, задайте `APPLE_BUNDLE_ID`, а для продакшена `APPLE_ENVIRONMENT=Production` и `APPLE_APP_ID`.
- **Google Play Console:** создайте две подписки с этими ID (у каждой есть базовый тариф). Создайте сервисный аккаунт с доступом к Play Developer API, сохраните JSON-ключ на сервере и укажите путь в `GOOGLE_SERVICE_ACCOUNT_FILE`. Покупки в Google Play работают, только когда приложение установлено из Play (подойдёт внутренний тестовый трек).

Приложения проверяют подписку при каждом запуске, поэтому продление и отмена подхватываются автоматически.

## Модель ИИ

Сервер использует `claude-opus-5-5` (переменная `AURA_MODEL`) с адаптивным мышлением и потоковой передачей:
- бесплатный план: глубина `low` для чата и идей, `medium` для кода;
- Pro: `medium` для чата и идей, `high` для кода.

Если запрос отклонён фильтрами безопасности, API автоматически повторяет его на рекомендованной резервной модели (`fallbacks: "default"`). Если и она отказывает, приложение показывает понятное сообщение.

## API сервера (для справки)

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/api/auth/register`, `/api/auth/login`, `/api/auth/logout` | аккаунт |
| GET/PATCH/DELETE | `/api/me` | профиль, настройки, удаление |
| POST | `/api/me/password` | смена пароля |
| GET/POST/DELETE | `/api/chats` | список, создание, очистка истории (`?q=` для поиска) |
| PATCH/DELETE | `/api/chats/:id` | переименовать, удалить |
| GET | `/api/chats/:id/messages` | сообщения |
| POST | `/api/chats/:id/messages` | отправить сообщение, ответ потоком (SSE) |
| POST | `/api/chats/:id/regenerate` | повторить последний ответ (SSE) |
| POST | `/api/uploads` | загрузить файл (тело запроса = файл, имя в `X-File-Name`) |
| GET/POST/DELETE | `/api/images` | галерея и генерация |
| POST | `/api/subscription/verify` | проверить покупку Apple или Google |
